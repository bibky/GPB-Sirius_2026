# Перепланирование MDVRP после отмены клиентов

Вечером известно решение R* для всех клиентов. Утром часть клиентов отменяет доставку, и маршруты нужно быстро пересчитать. Вместо решения задачи заново поправляем R*.

## Алгоритм

1. **Вычеркнуть** отменившихся клиентов из маршрутов. Расстояния d — кратчайшие пути в графе, для них выполнено неравенство треугольника, поэтому маршрут не дорожает. Решение сразу допустимо.
2. **Локальный поиск** (перенос клиента, обмен двух клиентов, слияние двух маршрутов). Начинаем только с клиентов машин, из которых кого-то вычеркнули, и клиентов, у которых они среди ближайших соседей. Остальная часть R* не изменилась, улучшить её нечем.
3. **LNS**: несколько раз вынимаем клиента и 4 его соседей рядом с изменениями, вставляем жадно заново, оставляем результат, если стало дешевле.

## Запуск

Нужны `numpy` и `matplotlib`. Открыть `mdvrp_short.ipynb` и выполнить все ячейки.

## Пример

3 склада по 4 машины, не больше 6 клиентов на машину, 60 клиентов, утром 6 отмен.
